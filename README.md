# PRODIGY_WD_01

## Responsive Landing Page

A modern, responsive single-page landing website created as **Task 01** during my Web Development Internship at **Prodigy Infotech**.

The page presents Prodigy Infotech as a future-focused technology company and includes an interactive navigation experience that makes it easy to move through the site on desktop, tablet, and mobile screens.

## Live Demo

[View the live website](https://keerthivasan986.github.io/PRODIGY_WD_01/)

## Features

- Fixed navigation bar that remains visible while scrolling
- Smooth scrolling between page sections
- Active navigation state that updates according to the section in view
- Responsive layout for desktop, tablet, and mobile devices
- Hero section with a clear call to action
- Core solutions grid covering AI, full-stack development, cybersecurity, and emerging technology
- Impact and vision section with achievement statistics
- Contact section with email, phone, location, and a second call to action
- Hover states and visual feedback for navigation links, buttons, and solution cards

## Page Sections

- **Index:** Introduction to Prodigy Infotech and its technology vision
- **Services:** Overview of the company’s core technology solutions
- **About Us:** Company impact, vision, and program statistics
- **Contact:** Communication details and collaboration call to action

## Technologies Used

- HTML5 for semantic page structure
- CSS3 for layout, responsive design, colors, typography, transitions, and visual styling
- JavaScript for smooth scrolling, active navigation tracking, and interactive buttons
- Google Fonts using Poppins and Roboto

## Project Structure

```text
PRODIGY_WD_01/
├── index.html   # Main landing page
├── style.css    # Layout, theme, responsive styles, and animations
├── script.js    # Navigation and scrolling interactions
└── README.md    # Project documentation
```

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Scroll through the page or use the fixed navigation menu to explore each section.

No build tools or external installation are required.
